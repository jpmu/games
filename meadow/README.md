# Meadow Walk

A small top-down pixel-art meadow you can walk around in.

- `index.html`: the game. Open it in a browser. It loads `sprites.png` from the same folder.
- `sprites.png`: 4×4 transparent sprite sheet with 128px frames. Row 0 walks down, row 1 is the idle side poses, row 2 walks right (it's mirrored for left), and row 3 walks up.
- `source/gemini-sheet.jpeg`: the generated sheet the frames were cut from. This copy is slightly downsized from the original.

Controls: WASD or arrow keys to walk, Shift to run. On touch screens, drag anywhere to walk and push far to run.
